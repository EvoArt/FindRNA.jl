# Bacterial rRNA profiles

`bac.hmm` is the unmodified nucleotide profile database from
https://github.com/tseemann/barrnap/blob/0.9/db/bac.hmm.
It contains Rfam RF00177 (16S), RF02541 (23S), and RF00001 (5S).
SHA-256: `63e4093feeb24c6fb96f768df91ca9360210ed523af6151baaab4f2095e07bc3`.
Rfam data are CC0; see the upstream notice in `LICENSE.Rfam`.
No barrnap executable code is bundled.
